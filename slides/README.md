# Presentación - Akinator Disney

Presentación del proyecto usando [Slidev](https://sli.dev/).

## Desarrollo

```bash
cd slides
pnpm install  # si aún no instalaste
pnpm dev
```

Abre http://localhost:3030

## Exportar

**PDF:**
```bash
pnpm export
```

**HTML estático:**
```bash
pnpm build
```

## Estructura

- `slides.md` - Contenido de la presentación
- `public/` - Assets (imágenes, screenshots)

## Tips

- Usa **Espacio** o **→** para avanzar
- **←** para retroceder
- **ESC** para vista general
- **O** para modo presentador (con notas)
